# Código de Conducta de ForgeMind Intuition

## Nuestro compromiso

Queremos que ForgeMind Intuition sea un espacio técnico, experimental y respetuoso para quienes trabajan en síntesis de programas, inferencia, álgebra, agentes de código y herramientas de desarrollo. Todas las personas que participen en el proyecto deben poder hacerlo sin acoso, discriminación ni intimidación.

## Conductas esperadas

Se espera comunicación clara, consideración por las perspectivas diferentes, crítica centrada en ideas y código, documentación de decisiones técnicas y disposición para corregir errores. Las discusiones sobre resultados experimentales deben distinguir entre evidencia, hipótesis, opinión y limitaciones.

## Conductas no aceptables

No se toleran ataques personales, lenguaje discriminatorio, acoso, amenazas, publicación de información privada, suplantación, spam, sabotaje deliberado, manipulación de benchmarks ni presentación de datos inventados como resultados reales. Tampoco se aceptan credenciales, tokens o información sensible publicada en issues, discusiones, pull requests o commits.

## Alcance

Este código se aplica a issues, pull requests, Discussions, revisiones de código, commits, canales externos vinculados al proyecto y cualquier espacio en el que una persona represente oficialmente a ForgeMind.

## Aplicación

Los mantenedores pueden editar, ocultar o cerrar contenido que incumpla estas reglas, solicitar una corrección, limitar temporalmente la participación o retirar permisos cuando sea necesario para proteger a la comunidad. Las decisiones deben ser proporcionales, explicar el motivo cuando sea posible y evitar la exposición pública de información sensible.

## Reportes

Para reportar una conducta problemática, utiliza un canal privado indicado en [`SECURITY.md`](SECURITY.md) cuando exista riesgo de seguridad o privacidad. Para problemas comunitarios no sensibles, abre una issue privada o contacta a los mantenedores sin publicar datos personales.

## Atribución

Este documento adapta el espíritu del [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) a las necesidades de un proyecto experimental de software.
