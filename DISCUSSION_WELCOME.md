# Welcome to ForgeMind-Intuition Discussions!

ForgeMind Intuition es un proyecto abierto para explorar una idea sencilla y exigente: ¿podemos mejorar la síntesis de programas si buscamos activamente los experimentos que podrían falsar nuestras hipótesis?

El repositorio combina tres líneas de trabajo:

1. **Núcleo algebraico:** representación, canonicalización, composición y ejecución de candidatas.
2. **Inferencia y decisión:** memoria experimental, puntuación explicable, Bayes, `log_weight`, `top_k` y eliminación con procedencia.
3. **Producto y agentes:** CLI, proyectos reproducibles, frontend y futuras integraciones para herramientas de código.

Este espacio sirve para discutir arquitectura, experimentos, benchmarks, integraciones y casos de uso. Las preguntas técnicas son bienvenidas, especialmente cuando incluyen una entrada reproducible, una hipótesis clara o un contraejemplo.

## Cómo participar

Puedes abrir una Discussion para presentar una idea, preguntar por una API, proponer un benchmark o compartir una observación. Para bugs reproducibles utiliza la plantilla de issue. Para vulnerabilidades o credenciales expuestas, sigue [`SECURITY.md`](../SECURITY.md) y no publiques información sensible.

## Reglas de la conversación

Critiquemos hipótesis, código y mediciones; no a las personas. Distingamos entre posterior, predicción, equivalencia semántica y prueba. No presentemos resultados sintéticos como evidencia real y documentemos los límites de cada experimento.

## Primeras preguntas

- ¿Qué proyecto de código te gustaría analizar con ForgeMind?
- ¿Qué tipo de contraejemplo te ha resultado más útil para descartar una solución?
- ¿Qué debería devolver un agente cuando varias candidatas tienen probabilidades similares?
- ¿Qué benchmark sería más informativo para comparar la intuición activa con una búsqueda pasiva?

Gracias por ayudar a construir una herramienta de razonamiento experimental para código que sea útil, explicable y honesta sobre su incertidumbre.
